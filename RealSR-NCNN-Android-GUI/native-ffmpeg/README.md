# FFmpeg video software decoder (ARM64, API 24)

Build: `python native-ffmpeg/build.py` from the Gradle root. `preBuild` invokes this automatically. All downloaded/build dependencies remain private under `F:/videoimageupscaler/toolchain`; no global SDK/config edits. Requires installed Git Bash, Python (3.14 for initial MSYS zstd extraction), Visual Studio C runtime headers/libs (14.51.36231 / Windows SDK 10.0.26100.0), and the existing private NDK r28c. The Microsoft tools are used only to run FFmpeg's host generators and the native policy test; all Android code is compiled by NDK Clang for `aarch64-linux-android24`.

Source: https://ffmpeg.org/releases/ffmpeg-7.1.2.tar.xz
SHA256: `089bc60fb59d6aecc5d994ff530fd0dcb3ee39aa55867849a2bbc4e555f9c304` (independently matches https://mirrors.omnios.org/ffmpeg/ffmpeg-7.1.2.tar.xz.sha256).
GNU Make package: https://repo.msys2.org/msys/x86_64/make-4.4.1-2-x86_64.pkg.tar.zst
SHA256: `2408af61717dae87b00c855b132769a125c708907fc94a46bb16dae076113e5c`. Private make runs with Git's MSYS runtime. Make's GPL license applies to the build tool, not the resulting FFmpeg library.
NDK: https://dl.google.com/android/repository/android-ndk-r28c-windows.zip (existing private bootstrap/hash files retained). NDK exact version is checked before compiling.

FFmpeg configure explicitly disables GPL/nonfree, external autodetection, network, protocols, encoders, hardware accelerators and programs. Enabled LGPL software decoders: AVC, HEVC, VP8, VP9 and MPEG4 (FFmpeg internally enables its H263 dependency). Demuxers built: MOV/MP4, Matroska/WebM, AVI, MPEGTS. MPEGTS is explicitly rejected by the JNI wrapper because Android rebases transport timestamps while FFmpeg preserves them; use the MediaCodec path for TS until a shared timeline mapping is implemented. AV1 is explicitly unsupported. FFmpeg reports **LGPL version 2.1 or later**. License: https://ffmpeg.org/legal.html and https://www.gnu.org/licenses/old-licenses/lgpl-2.1.html . No FFmpegKit/Maven binary dependencies.

JNI duplicates and owns a seekable descriptor. Custom 32KiB AVIO uses `pread` within the exact asset offset/length and never copies the source or writes PNGs. Unknown declared length is resolved with `fstat`; unknown/nonseekable extents fail visibly. It receives one decoded frame at a time and flushes delayed frames at genuine demuxer EOS. Source best-effort PTS is rescaled from the original stream timebase, not synthesized. Preview seek is backward to a keyframe; caller filters preroll. Crops are applied explicitly (codec auto-cropping disabled). Rotation metadata is deliberately not applied.

Only 8-bit SDR, stable coded/visible dimensions and BT601/709 matrices are accepted. An untagged matrix is inferred from height (>=720 => BT709, otherwise BT601), disclosed in diagnostics. Range comes from each decoded frame. Decoder maximum pixels 16,777,216; dimensions <=8192; individual FFmpeg allocations <=128MiB; packets <=32MiB after demuxing; configured threads 1..16. These limits bound resources but do not constitute a fixed aggregate RSS cap (reference frames/thread buffers remain codec-dependent). Missing/negative timestamps, HDR/10bit, source I/O errors, unsupported matrices/codecs and malformed handles propagate exceptions, never false EOS or automatic fallback.

Java `next`/`close` are synchronized; JNI registry validates opaque monotonically allocated handles, serializing calls/close. Returned Bitmap belongs to caller. Cancellation is checked before/after JNI and recycles a newly returned bitmap when cancelled. FFmpeg has a cooperative 30-second demux/decode deadline. A blocked provider `pread` or an individual codec operation cannot be forcibly interrupted: cancellation/close waits for that in-flight call. No false hard-timeout guarantee.

## Static LGPL relinking and distribution

Deliver `F:/videoimageupscaler/ffmpeg-video-lgpl-relink/` alongside **every APK** containing this library. It contains the exact unmodified FFmpeg source tarball; COPYING.LGPLv2.1; LICENSE.md; the complete wrapper/JNI build source; configure flags/config/logs; all four static archives; the independently relocatable `ffmpeg_video.o`; generated `relink-command.json`; SHA256 manifest and the unstripped resulting `.so`. Objects inside the archives are retained so FFmpeg may be replaced/modified and relinked, rather than merely offering a stripped binary.

Relink with private NDK r28c Clang++ using the JSON argument array (paths can be relocated to your chosen NDK/kit): compile modified FFmpeg with `configure-build.sh`, replace the four `libav*.a`/`libswscale.a` archives, then run the shared-library link command retaining `ffmpeg_video.o`. JNI and FFmpeg changes can alternatively be rebuilt from all supplied sources. The APK includes license/notices under `assets/ffmpeg/`. Replace the APK's `lib/arm64-v8a/libffmpeg_video.so` with the relinked library, zipalign for 16KiB and sign the replacement APK with your own key; Android signature rules may require uninstalling the original first. No technical restriction is imposed on such debugging/modification/reverse-engineering for LGPL purposes; no private original signing key is necessary to run your modified installation. Keep the app's own license obligations separately. Do not distribute just the APK without its corresponding relink kit/source/notices.

## Verification

`python native-ffmpeg/test-host.py`: actual Windows-native C++ AVIO extent/seek bounds tests (not simulated Android decoding).
`./gradlew :app:compileDebugAndroidTestJavaWithJavac`: wrapper and real-codec instrumentation compile. Tests generate an actual small AVC/MP4 VFR fixture using MediaCodec/EGL without NCNN models; assert original PTS, color, dimensions/unrotated output, genuine/repeated EOS, cancellation, idempotent close, invalid-input errors, descriptor duplication plus offset/length bounds, and backward-keyframe seeking. These tests remain **unexecuted until a real ARM64 phone is attached**. Compiling is not device verification.

Inspect `llvm-readelf -h -l -d` and Android notes on the exact resulting library: ELF64 AArch64, API24 note, every PT_LOAD alignment 0x4000, and only Android system DT_NEEDED entries (no avformat/avcodec/avutil/swscale/libc++ shared dependencies). Final APK zipalign/signature/phone checks belong to release integration, not this build alone. Logs in this directory record red compilation (missing decoder contract), native build, ELF and green instrumentation compilation. FFmpeg upstream emits a few conversion/assembly warnings; current Java/Gradle builds emit existing deprecated API/Gradle warnings.
